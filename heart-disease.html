TEAM PROJECT / MACHINE LEARNING

心臟疾病預測及
預防管理系統

以心血管疾病相關資料為基礎，結合機器學習演算法進行模型建置， 並整合前端介面，讓使用者能夠輸入資料並了解相關預測資訊。

大學團隊專題 專題組長 Machine Learning R / Python

OVERVIEW

專案介紹

從資料分析、模型建置到系統整合的團隊專題實作。

本專題以心臟疾病預測及預防管理為主題， 希望透過資料分析與機器學習方法， 建立能夠提供使用者參考的預測系統。

系統包含使用者資料輸入、演算法介紹、 心血管疾病相關資訊，以及不同模型的驗算示意， 將資料分析與前端介面結合。

專題期間我擔任團隊組長，除了參與 R 語言與 Python 的模型建置，也負責團隊工作分配與進度協調， 並參與部分前端製作及 JavaScript 串接。
